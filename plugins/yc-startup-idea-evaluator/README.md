# yc-startup-idea-evaluator

Evaluate a startup idea the way a Y Combinator partner would, with cited sources. Unofficial, not affiliated with Y Combinator.

Install in Claude Code:

```
/plugin install yc-startup-idea-evaluator --marketplace carlosmgv02/yc-startup-idea-evaluator
```

See the [repository README](../../README.md) for what it does, other ways to install it and its limits.
